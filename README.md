## 使用

在线阅读支持章节导航、全文检索、公式排版、解答折叠与补充问答。笔记和自评保存在当前浏览器，可自行导出备份。下载仓库后也可以打开 `site/index.html` 离线阅读。

```bash
npm ci
npm run build
npm start
```

构建只写仓库内文件，不安装后台服务。依赖已锁定，页面运行不使用 CDN。
