## H2-8-5｜泊松高阶矩递推

<p class="question-scope midterm">期中进度内</p>

<div class="source-chips"><button data-source="handout" data-page="60">学生总讲义 · PDF 60</button> <button data-source="handout" data-page="61">学生总讲义 · PDF 61</button> <button data-source="p56" data-page="41">AI_中的数学 第五六讲 · PDF 41</button> <button data-source="p56" data-page="42">AI_中的数学 第五六讲 · PDF 42</button> <button data-source="handout3" data-page="58">新版本科生讲义 · 截至第三章前半 · PDF 58</button> <button data-source="handout3" data-page="59">新版本科生讲义 · 截至第三章前半 · PDF 59</button></div>

设 $X\sim\operatorname{Pois}(\lambda)$，$\lambda>0$。对每个正整数 $m$，证明 $E(X^m)=\lambda E[(X+1)^{m-1}]$，并利用该递推求 $E(X^3)$。



<details>
<summary>展开解答与易错点</summary>

泊松概率含 $k!$，所以用取值中的一个 $k$ 约掉阶乘，是最直接的起笔方法。对整数 $m\ge1$，
$$EX^m=\sum_{k=1}^\infty k^m e^{-\lambda}\frac{\lambda^k}{k!}
=\lambda\sum_{k=1}^\infty k^{m-1}e^{-\lambda}\frac{\lambda^{k-1}}{(k-1)!}.$$
令 $j=k-1$，则 $k=j+1$，求和起点变成0：
$$EX^m=\lambda\sum_{j=0}^\infty(j+1)^{m-1}P(X=j)=\lambda E(X+1)^{m-1}.$$
依次取 $m=1,2,3$：$EX=\lambda$，$EX^2=\lambda(EX+1)=\lambda^2+\lambda$，
$$EX^3=\lambda(EX^2+2EX+1)=\lambda^3+3\lambda^2+\lambda.$$
换下标时，幂中的 $k$ 也必须换成 $j+1$，不能只改阶乘。

[Q003：泊松矩递推中，换下标后为什么能写成期望？](qa:08/Q003)



</details>


## H2-9-1｜标准正态的所有整数矩

<p class="question-scope midterm">期中进度内</p>

<div class="source-chips"><button data-source="handout" data-page="68">学生总讲义 · PDF 68</button> <button data-source="handout" data-page="69">学生总讲义 · PDF 69</button> <button data-source="p7" data-page="22">AI_中的数学_概率与统计部分 7.5 · PDF 22</button> <button data-source="p7" data-page="23">AI_中的数学_概率与统计部分 7.5 · PDF 23</button> <button data-source="p7" data-page="24">AI_中的数学_概率与统计部分 7.5 · PDF 24</button> <button data-source="handout3" data-page="66">新版本科生讲义 · 截至第三章前半 · PDF 66</button> <button data-source="handout3" data-page="67">新版本科生讲义 · 截至第三章前半 · PDF 67</button></div>

$X\sim N(0,1)$，证明奇数阶矩为 0，$E(X^{2k})=(2k-1)(2k-3)\cdots1$。



<details>
<summary>展开解答与易错点</summary>

记 $m_r=EX^r=\int_{-\infty}^{\infty}x^r\phi(x)dx$，其中 $\phi(x)=e^{-x^2/2}/\sqrt{2\pi}$。奇数次幂乘偶函数仍是奇函数，正负两边积分抵消，所以奇数阶矩为0。

偶数阶利用 $\phi'(x)=-x\phi(x)$ 降低幂次。把一个 $x\phi(x)dx$ 写成 $-d\phi(x)$，分部积分得
$$m_{2k}=-\int x^{2k-1}d\phi(x)
=-[x^{2k-1}\phi(x)]_{-\infty}^{\infty}+(2k-1)\int x^{2k-2}\phi(x)dx.$$
高斯指数衰减使边界项为0，因此 $m_{2k}=(2k-1)m_{2k-2}$。从 $m_0=1$ 往回递推：
$$EX^{2k}=(2k-1)(2k-3)\cdots1.$$
例如 $EX^2=1,EX^4=3,EX^6=15$。原点矩是“先取幂再平均”，不是均值的幂。



</details>


## H2-9-2｜Pareto 分布的期望和方差

<p class="question-scope midterm">期中进度内</p>

<div class="source-chips"><button data-source="handout" data-page="69">学生总讲义 · PDF 69</button> <button data-source="p7" data-page="25">AI_中的数学_概率与统计部分 7.5 · PDF 25</button> <button data-source="p7" data-page="26">AI_中的数学_概率与统计部分 7.5 · PDF 26</button> <button data-source="handout3" data-page="67">新版本科生讲义 · 截至第三章前半 · PDF 67</button></div>

$f(x)=k\theta^k/x^{k+1}$，$x>\theta>0$，$k>2$。求 $EX$ 与 $\operatorname{Var}(X)$。



<details>
<summary>展开解答与易错点</summary>

密度是幂函数，先将 $x^r$ 乘进去，统一计算一、二阶矩。对 $r<k$，
$$EX^r=k\theta^k\int_\theta^\infty x^{r-k-1}dx
=k\theta^k\left[\frac{x^{r-k}}{r-k}\right]_\theta^\infty
=\frac{k\theta^r}{k-r}.$$
这里 $r-k<0$，所以无穷远的幂趋于0；若 $r\ge k$，对应正阶矩发散。

本题 $k>2$，可取 $r=1,2$，得到 $EX=k\theta/(k-1)$、$EX^2=k\theta^2/(k-2)$。于是
$$\operatorname{Var}X=\theta^2\left[\frac{k}{k-2}-\frac{k^2}{(k-1)^2}\right]
=\frac{k\theta^2}{(k-2)(k-1)^2}.$$
通分后的分子为 $k(k-1)^2-k^2(k-2)=k$。原讲义及PPT出现的负方差式有误；正确答案在 $k>2$ 时为正。



</details>

## H2-10-2｜正态矩公式的再次应用

<p class="question-scope midterm">期中进度内</p>

对标准正态 $X$，写出并证明所有正整数阶原点矩。



<details>
<summary>展开解答与易错点</summary>

这道题与 H2-9-1 是同一标准正态矩结论的再次出现，保留各自来源。奇数幂的积分因对称性为0；偶数幂用分部积分降两阶：

<details>
<summary>展开解答与易错点</summary>

## U11｜常见连续模型的均值方差

<p class="question-scope midterm">期中进度内</p>

<div class="source-chips"><button data-source="handout" data-page="56">学生总讲义 · PDF 56</button> <button data-source="handout" data-page="57">学生总讲义 · PDF 57</button> <button data-source="handout" data-page="66">学生总讲义 · PDF 66</button> <button data-source="handout" data-page="67">学生总讲义 · PDF 67</button> <button data-source="handout" data-page="68">学生总讲义 · PDF 68</button> <button data-source="p56" data-page="17">AI_中的数学 第五六讲 · PDF 17</button> <button data-source="p56" data-page="18">AI_中的数学 第五六讲 · PDF 18</button> <button data-source="p56" data-page="19">AI_中的数学 第五六讲 · PDF 19</button> <button data-source="p56" data-page="20">AI_中的数学 第五六讲 · PDF 20</button> <button data-source="p56" data-page="22">AI_中的数学 第五六讲 · PDF 22</button> <button data-source="p7" data-page="15">AI_中的数学_概率与统计部分 7.5 · PDF 15</button> <button data-source="p7" data-page="16">AI_中的数学_概率与统计部分 7.5 · PDF 16</button> <button data-source="p7" data-page="17">AI_中的数学_概率与统计部分 7.5 · PDF 17</button> <button data-source="p7" data-page="18">AI_中的数学_概率与统计部分 7.5 · PDF 18</button></div>

计算以下模型的均值和方差：（1）$U(a,b)$，$a<b$；（2）$\operatorname{Exp}(\lambda)$，速率 $\lambda>0$；（3）$N(\mu,\sigma^2)$，$\sigma>0$；（4）$\Gamma(\alpha,\beta)$，形状 $\alpha>0$、速率 $\beta>0$，密度为 $\beta^\alpha x^{\alpha-1}e^{-\beta x}/\Gamma(\alpha)$（$x>0$），其余为0。另对标准柯西密度 $1/[\pi(1+x^2)]$ 说明期望是否存在，以及为何不能仅由对称性断言均值为0。



<details>
<summary>展开解答与易错点</summary>

**均匀分布。** 先在 $(0,1)$ 上积分：$EU=\int_0^1u\,du=1/2$，$EU^2=\int_0^1u^2du=1/3$，所以方差为 $1/12$。一般的 $X=a+(b-a)U$ 给出
$$EX=\frac{a+b}{2},\qquad\operatorname{Var}X=\frac{(b-a)^2}{12}.$$

**指数分布。** 尾概率是 $e^{-\lambda t}$，尾积分得 $EX=1/\lambda$。对二阶矩分部积分，边界项为0：
$$EX^2=\int_0^\infty x^2\lambda e^{-\lambda x}dx
=2\int_0^\infty xe^{-\lambda x}dx=\frac2{\lambda^2}.$$
减去均值平方得方差 $1/\lambda^2$。

**正态分布。** 标准化写成 $X=\mu+\sigma Z$。由 $EZ=0,EZ^2=1$，立刻有 $EX=\mu$、$\operatorname{Var}X=\sigma^2$。

**伽马部分只需了解：** 采用形状 $\alpha$、速率 $\beta$ 时，均值为 $\alpha/\beta$，方差为 $\alpha/\beta^2$。它来自将矩积分识别成 $EX^r=\Gamma(\alpha+r)/(\Gamma(\alpha)\beta^r)$，指数分布是 $\alpha=1$ 的特例。

**柯西的存在性检查。** 对称不等于均值存在。正半轴有
$$\int_0^A\frac{x}{\pi(1+x^2)}dx=\frac1{2\pi}\ln(1+A^2)\to\infty.$$
负半轴同样不能绝对积分，故均值不存在；对称截断得到0只是主值，不是期望。



</details>


## U13｜方差恒等式及最优常数

<p class="question-scope midterm">期中进度内</p>

<div class="source-chips"><button data-source="handout" data-page="63">学生总讲义 · PDF 63</button> <button data-source="handout" data-page="64">学生总讲义 · PDF 64</button> <button data-source="handout" data-page="65">学生总讲义 · PDF 65</button> <button data-source="p7" data-page="7">AI_中的数学_概率与统计部分 7.5 · PDF 7</button> <button data-source="p7" data-page="8">AI_中的数学_概率与统计部分 7.5 · PDF 8</button> <button data-source="p7" data-page="9">AI_中的数学_概率与统计部分 7.5 · PDF 9</button> <button data-source="p7" data-page="10">AI_中的数学_概率与统计部分 7.5 · PDF 10</button> <button data-source="p7" data-page="11">AI_中的数学_概率与统计部分 7.5 · PDF 11</button> <button data-source="p7" data-page="19">AI_中的数学_概率与统计部分 7.5 · PDF 19</button></div>

设实值随机变量 $X$ 满足 $EX^2<\infty$，$a,b,c$ 为实常数。证明 $\operatorname{Var}X=EX^2-(EX)^2$、$\operatorname{Var}(aX+b)=a^2\operatorname{Var}X$，以及 $\inf_{c\in\mathbb R}E(X-c)^2=\operatorname{Var}X$；说明最优常数 $c$ 是什么。



<details>
<summary>展开解答与易错点</summary>

设 $\mu=EX$。将定义中的平方展开，逐项取期望：
$$\operatorname{Var}X=E(X^2-2\mu X+\mu^2)=EX^2-2\mu^2+\mu^2=EX^2-\mu^2.$$
对 $aX+b$，其均值为 $a\mu+b$，因此中心化后只剩 $a(X-\mu)$，平方并平均得到方差 $a^2\operatorname{Var}X$。

最后把预测误差写成 $X-c=(X-\mu)+(\mu-c)$。展开后，交叉项含 $E(X-\mu)=0$，所以
$$E(X-c)^2=\operatorname{Var}X+(\mu-c)^2.$$
第一项不随 $c$ 变化，第二项非负且仅在 $c=\mu$ 时为0。因此最优常数是 $EX$，最小值为方差。



</details>

## P52｜图示：两倍标准差外的概率界

<p class="question-scope midterm">期中进度内</p>

<div class="source-chips"><button data-source="p7" data-page="6">AI_中的数学_概率与统计部分 7.5 · PDF 6</button></div>

解释 PPT 切比雪夫图中的 $P(|X-\mu|\ge2\sigma)\le1/4$，并说明若 $X$ 恰为正态，实际尾概率是多少。



<details>
<summary>展开解答与易错点</summary>

切比雪夫部分按了解处理：令偏差阈值为 $2\sigma$，得到上界 $\sigma^2/(2\sigma)^2=1/4$，要求 $\sigma>0$。

正态计算需要掌握。若 $X\sim N(\mu,\sigma^2)$，令 $Z=(X-\mu)/\sigma$，则
$$P(|X-\mu|\ge2\sigma)=P(|Z|\ge2)=2[1-\Phi(2)]\approx0.0455.$$
乘2来自两侧对称的尾面积。$1/4$ 是一般上界，0.0455是正态模型下的实际概率，二者不是同一种信息。



</details>
