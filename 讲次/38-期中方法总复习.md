## 先按题目所问，找到方法

| 题目问法或条件 | 优先考虑 |
| --- | --- |
| 至少一次、至少一个、全部没有 | 补事件；有独立性才能乘失败概率 |
| 等可能地选、排、抽；放回或不放回 | 先确定样本空间，再选排列组合模型 |
| 已知某事发生；观察结果倒推来源 | 条件概率；全概率补分母；Bayes |
| 第一次、直到、先达到、返回重来 | 固定停止的最后一步，或分状态递推 |
| 求新变量的分布 | 离散合并概率；连续先 CDF，合适时用换元 |
| 求一个事件的概率 | 只在符合事件的区域积分，不一定先求新分布 |
| 求总个数的平均值 | 示性变量相加 |
| 求函数的平均值 | 直接对原分布加权，不必先求函数的分布 |
| 给尾概率、等待时间、截顶 | 尾和或尾积分 |
| 求方差、二阶矩、最优固定预测 | $EX^2-(EX)^2$；平方误差分解 |
| 求边缘、条件密度、判断独立 | 画支持、找切片；积分、相除、全域比较 |
| 求和、比值、两个输出、距离 | 卷积、辅助变量、雅可比、极坐标 |
| 正态变量比较大小或条件预测 | 先确认联合正态，再用和差或条件正态 |
| 总数或环境随机 | 先固定它算条件均值，再用重期望 |

大写 $X,Y$ 表示随机变量，小写 $x,y$ 表示取值或阈值。$f_X(x)$ 是密度；$F_X(x)=P(X\le x)$ 才是累计概率。期望中的括号要读清：$E(X^2)$ 与 $(EX)^2$ 不是同一个量。

## 模块一｜先把文字变成事件

$A\cup B$ 是至少一个发生，$A\cap B$（也写 $AB$）是两个都发生，$A^c$ 是不发生，$A-B=AB^c$ 是 $A$ 发生而 $B$ 不发生。

$$\begin{aligned}
P(A^c)&=1-P(A),\\
P(A\cup B)&=P(A)+P(B)-P(AB),\\
P(A-B)&=P(A)-P(AB),\\
(A\cup B)^c&=A^cB^c,\qquad(AB)^c=A^c\cup B^c.
\end{aligned}$$

“恰好一个”要把两个互斥情况相加：

$$P(AB^c\cup A^cB)=P(A)+P(B)-2P(AB).$$

三事件容斥：各单项相加，减去三个两两交集，再加回三者交集。检查调查人数是否矛盾时，算出的并集不能超过总人数，各种“恰好属于”的人数也不能为负。

**例子：** 已知 $P(A)=0.6,P(B)=0.5,P(AB)=0.3$，则至少一个发生的概率为 $0.8$，恰好一个为 $0.5$，一个也不发生为 $0.2$。这里没有假设独立。

对于 $n$ 个事件，“恰好 $r$ 个发生”可按所有大小为 $r$ 的指标集合分类：选中的事件取交，未选中的取补后再交，最后相加。独立同成功率时，这一步会化成二项分布。

区间的可数并、交可以先画端点：$\bigcup_{n\ge1}(1/n,1)=(0,1)$；$\bigcap_{n\ge1}(-1/n,1/n)=\{0\}$。单点在连续分布下可以概率为零，但事件并非空集。$P(AB)=0$ 也不能直接说 $A,B$ 互斥；只能说交集是零概率事件。

## 模块二｜计数：先统一样本空间，再除

只有所有基本结果等可能时，才能写 $P(A)=\#A/\#\Omega$。分子分母必须用同一计数口径；有序、无序不能混用。

| 从 $n$ 个不同对象中取 $r$ 次/个 | 计数 |
| --- | --- |
| 不放回、有序，$r\le n$ | $n(n-1)\cdots(n-r+1)=n!/(n-r)!$ |
| 不放回、无序，$r\le n$ | $\binom nr=n!/[r!(n-r)!]$ |
| 放回、有序 | $n^r$ |
| 可重复、无序，只计各类次数 | $\binom{n+r-1}{r}$，不自动表示这些结果等可能 |

可重复无序取法对应 $x_1+\cdots+x_n=r$、$x_i\ge0$：排 $r$ 个星号和 $n-1$ 块隔板，选星号位置即可。若每类至少一个，先令 $x_i'=x_i-1$，得到 $\binom{r-1}{n-1}$（$r\ge n$）。例如3种物品可重复无序取4件，计数为 $\binom64=15$。若实际是独立等概率抽4次，各多重集合的概率并不相等，因为对应的有序序列数不同。

**分组与分层。** 将 $n$ 个不同元素分到有标号、大小分别为 $r_1,\ldots,r_k$ 的组中，$\sum r_i=n$，方案数为 $n!/\prod r_i!$。从不同类别分别选取时乘 $\prod_j\binom{n_j}{r_j}$；这是计数乘法，不是在断言随机事件独立。

**双计数证明组合恒等式。** 从两组共 $a+b$ 个元素选 $r$ 个，可以直接数，也可以按第一组取了 $i$ 个分类：

$$\binom{a+b}{r}=\sum_i\binom ai\binom b{r-i}.$$

求和只遍历合法 $i$，或约定越界组合数为零。取 $a=b=n,r=n$ 得 $\sum_i\binom ni^2=\binom{2n}n$。

**有停止规则时，先固定最后一步。** 每局独立甲胜率 $p$，乙胜率 $q=1-p$，甲先赢 $m$ 局或乙先赢 $n$ 局就停。甲最终胜利且乙赢了 $k$ 局时，最后一局必须甲胜，前 $m+k-1$ 局中安排 $m-1$ 次甲胜：

$$P(\text{甲最终胜})=\sum_{k=0}^{n-1}\binom{m+k-1}{k}p^m q^k.$$

巴拿赫火柴盒更要区分“取走最后一根”与“再次选中空盒”。两盒各有 $n$ 根，每次独立等概率选盒，第一次选到空盒才停，另一盒剩 $r$ 根时

$$P(R=r)=2\binom{2n-r}{n}2^{-(2n-r+1)}=\binom{2n-r}{n}2^{-(2n-r)},\quad0\le r\le n.$$

组合数数的是停止前 $2n-r$ 次成功取火柴的选择，概率还要包括最后那次选空盒，前面的2表示哪一盒先被发现为空。

## 模块三｜条件概率、独立与 Bayes

$$P(A\mid B)=\frac{P(AB)}{P(B)},\quad P(B)>0;\qquad P(AB)=P(B)P(A\mid B).$$

条件横线右边是已知信息。例如三个孩子性别独立且男女等可能，已知至少一个女孩，剩下7种等可能结果；其中含男孩的有6种，故概率为 $6/7$。若信息是“指定的大孩子是女孩”，条件空间不同，不能复用 $6/7$。

连续多步事件用乘法链：

$$P(A_1\cdots A_n)=P(A_1)\prod_{i=2}^nP(A_i\mid A_1\cdots A_{i-1}),$$

使用条件概率时分母须有定义。不能未经独立性检查，把每一项都改成无条件概率。

**先按来源分组，再倒推来源。** 若 $B_i$ 互斥且穷尽、相应概率为正，

$$P(A)=\sum_iP(B_i)P(A\mid B_i),\qquad P(B_j\mid A)=\frac{P(B_j)P(A\mid B_j)}{\sum_iP(B_i)P(A\mid B_i)}.$$

教学例：两来源各占 $0.8,0.2$，次品率为 $0.01,0.05$。总次品率 $0.8(0.01)+0.2(0.05)=0.018$；已知次品后来自第二来源的概率为 $0.01/0.018=5/9$。先验权重不能漏。混淆矩阵中问“真的正类中判对多少”按真实类别分组；问“判为正类的里面真阳性多少”按预测结果分组，分母不同。

**独立与互斥分开。** 两事件独立要求 $P(AB)=P(A)P(B)$；互斥要求 $AB=\varnothing$。若两者概率均正，互斥反而不独立。$n$ 个事件相互独立，要求每个至少含两个事件的子组都满足乘积式；只检查两两或只检查全体都不够。

独立事件取补仍独立。证明时先示范一步：若 $C$ 是其余任意一组事件的交，

$$P(A^cC)=P(C)-P(AC)=[1-P(A)]P(C),$$

再对其他需取补的事件重复；必须覆盖任意子组。若 $A,B,C$ 相互独立，$A\cup B,AB,A-B$ 也分别与 $C$ 独立，可用容斥与差事件展开验证。

**至少成功一次。** 独立重复 $n$ 次，每次成功率 $p$，概率为 $1-(1-p)^n$。要求至少达到 $\alpha$ 时，$0<p,\alpha<1$，解

$$n\ge\frac{\log(1-\alpha)}{\log(1-p)}$$

后向上取整，注意除以负数使不等号翻转。串联系统全部工作才成功，概率为各工作率乘积；并联系统全坏才失败，失效概率为各失效率乘积。分支内部先算清，再合并；都需要相应独立性。

一个有用的代数判据：在 $0<P(A),P(B)<1$ 时，$P(A\mid B)>P(A\mid B^c)$ 等价于 $P(AB)>P(A)P(B)$，也等价于 $P(B\mid A)>P(B\mid A^c)$。证明把分母乘过去即可。

## 模块四｜递推概率：只记影响后续的状态

如果一轮后回到原状态，用未知概率表示“从现在起最终成功”的机会。每个状态列“各分支概率 × 分支后的成功概率”；已经赢的状态记1，已经输的状态记0。

**例子：** 连续独立投两枚公平骰子，和为7时甲赢，积为5时乙赢，其余重来。两种终止事件互斥，单轮概率分别 $a=6/36,b=2/36$。甲最终赢的概率 $q$ 满足

$$q=a+(1-a-b)q,\qquad q=\frac a{a+b}=\frac34.$$

这里每轮终止率为 $a+b>0$，一直不终止的概率为 $\lim_n(1-a-b)^n=0$。

若每局甲胜率 $p$，先累计领先两分者赢，设当前领先量为 $-1,0,1$，最终甲赢概率分别为 $h_{-1},h_0,h_1$，就写

$$h_0=ph_1+(1-p)h_{-1},\quad h_1=p+(1-p)h_0,\quad h_{-1}=ph_0.$$

代回得 $h_0=p^2/[p^2+(1-p)^2]$。如果后续还取决于“上一局是谁赢的”，则状态必须保留它，不能只用总局数。递推概率方程没有统一的“加1”；只有数局数的期望方程才会加本轮耗时。

若问“第 $n$ 步处于某状态的概率”，用上一时刻状态分组：设上一步在状态A时下一步到A的概率为 $a$，上一步不在A时下一步到A的概率为 $b$，且这些转移概率足以描述过程，则

$$q_{n+1}=aq_n+b(1-q_n).$$

给初值后可以逐次计算。若 $1-a+b\ne0$，令 $q_*=b/(1-a+b)$，有 $q_{n+1}-q_*=(a-b)(q_n-q_*)$，所以 $q_n=q_*+(a-b)^n(q_0-q_*)$；当 $|a-b|<1$ 时趋于 $q_*$。

## 模块五｜六种离散模型、众数与近似

下表令 $q=1-p$；几何分布统一记录首次成功所需的总次数。

| 模型与识别条件 | 概率与范围 | 均值、方差 |
| --- | --- | --- |
| 伯努利：一次试验是否成功 | $P(X=1)=p,P(X=0)=q$ | $p,pq$ |
| 二项：固定 $n$ 次独立同成功率试验，数成功次数 | $P(X=k)=\binom nkp^kq^{n-k}$，$k=0,\ldots,n$ | $np,npq$ |
| 泊松：给定区间内计数，参数 $\lambda>0$ | $P(X=k)=e^{-\lambda}\lambda^k/k!$，$k=0,1,\ldots$ | $\lambda,\lambda$ |
| 超几何：$N$ 件中 $D$ 件特殊，不放回抽 $n$ 件，数特殊件数 | $P(X=k)=\binom Dk\binom{N-D}{n-k}/\binom Nn$，$\max(0,n-N+D)\le k\le\min(n,D)$ | $nD/N$；$N>1$ 时方差 $n(D/N)(1-D/N)(N-n)/(N-1)$ |
| 几何：独立同成功率，直到首次成功 | $P(X=k)=q^{k-1}p$，$k\ge1$ | $1/p,q/p^2$ |
| 离散均匀：$1,\ldots,N$ 等可能 | $P(X=k)=1/N$ | $(N+1)/2,(N^2-1)/12$ |

超几何要求 $N\ge1,0\le D,n\le N$，且 $N,D,n$ 为整数；其余次数参数也按模型取整数。二项允许 $p=0,1$ 的退化情况；几何通常取 $0<p\le1$。超几何全抽时方差为0；只有一个物品的退化情形直接判断，不代含 $N-1$ 的式子。

“数成功”与“等成功”是两回事。5次射击中恰好2次成功用二项；首次成功在第5次用 $q^4p$。若只数首次成功前的失败数 $T=X-1$，则取值从0开始，$ET=q/p$，方差仍为 $q/p^2$。

**几何尾概率与无记忆。** $X>n$ 等价于前 $n$ 次全失败，所以 $P(X>n)=q^n$，进而

$$P(X>m+n\mid X>m)=q^n.$$

反过来，正整数值且几乎必然有限的变量若有这种无记忆性，记 $S(n)=P(X>n)$，则 $S(m+n)=S(m)S(n)$、$S(n)=S(1)^n$，故为几何分布；$S(1)=0$ 对应恒等于1。

**求最可能的整数：比较相邻概率，不对整数位置硬求导。**

$$\frac{P_{
m Bin}(k+1)}{P_{
m Bin}(k)}=\frac{n-k}{k+1}\frac p{1-p},\qquad\frac{P_{
m Pois}(k+1)}{P_{
m Pois}(k)}=\frac\lambda{k+1}.$$

二项在 $(n+1)p$ 非整数时众数为 $\lfloor(n+1)p\rfloor$；为整数 $r$ 时有 $r-1,r$ 两个众数（$0<p<1$）。泊松在 $\lambda$ 非整数时众数为 $\lfloor\lambda\rfloor$；正整数 $\lambda$ 时有 $\lambda-1,\lambda$。例如 $P(X=1)=P(X=2)$、$X\sim\operatorname{Pois}(\lambda),\lambda>0$，由比值 $\lambda/2=1$ 得 $\lambda=2$。

**近似要写条件。** 二项在 $n$ 大、$p$ 小时可近似泊松，参数取 $np$；超几何在总体很大、抽样比例很小时可近似二项，$p=D/N$。这是近似，不是精确等号，也不把不放回真正变成独立。

要求证明极限时，用固定 $k$ 下的分解：若 $np_n\to\lambda>0$，

$$\binom nkp_n^k(1-p_n)^{n-k}=\frac{(np_n)^k}{k!}\prod_{j=0}^{k-1}(1-j/n)(1-p_n)^n(1-p_n)^{-k}\longrightarrow\frac{\lambda^k}{k!}e^{-\lambda}.$$

其中 $n\log(1-p_n)\to-\lambda$。超几何用下降阶乘 $(a)_r=a(a-1)\cdots(a-r+1)$：

$$P(X=k)=\binom nk\frac{(D)_k(N-D)_{n-k}}{(N)_n}.$$

固定 $n$、$D/N\to p$，将分子分母各除以相应次数的 $N$，各有限乘积分别趋于 $p^k,(1-p)^{n-k},1$，得到二项概率。

## 模块六｜连续密度、均匀、指数与正态

密度满足 $f\ge0,\int f=1$；区间概率是面积 $P(a<X<b)=\int_a^bf(x)dx$。密度可以大于1；有密度时单点概率为0，开闭端点不影响概率。

未知常数先归一化：若 $f(x)=cx$ 在 $(0,2)$ 内，其他处为0，则 $1=\int_0^2cx\,dx=2c$，得 $c=1/2$。要用题目给定的整个范围，不要提前加进后来所求事件。

| 模型 | 密度与分布函数 | 均值、方差 |
| --- | --- | --- |
| $U(a,b),a<b$ | $f=1/(b-a)$ 在 $(a,b)$ 内；$F=0$（$x\le a$）、$(x-a)/(b-a)$（$a<x<b$）、1（$x\ge b$） | $(a+b)/2,(b-a)^2/12$ |
| $\operatorname{Exp}(\lambda)$，速率 $\lambda>0$ | $f=\lambda e^{-\lambda x}$（$x>0$），$F=1-e^{-\lambda x}$（$x\ge0$），负半轴为0 | $1/\lambda,1/\lambda^2$ |
| $N(\mu,\sigma^2),\sigma>0$ | $f=e^{-(x-\mu)^2/(2\sigma^2)}/(\sqrt{2\pi}\sigma)$，全实轴；$F(x)=\Phi((x-\mu)/\sigma)$ | $\mu,\sigma^2$ |

均匀模型才能用“符合条件的长度/总长度”。公交每10分钟发车，若到达相位 $U\sim U(0,10)$，等待 $W=10-U$ 仍为 $U(0,10)$，故 $P(W<3)=3/10$；“随机到达”本身不自动意味着均匀。

指数的尾概率为 $P(X>t)=e^{-\lambda t}$（$t\ge0$），所以

$$P(a<X\le b)=e^{-\lambda a}-e^{-\lambda b},\quad0\le a<b;\qquad P(X>s+t\mid X>s)=e^{-\lambda t}.$$

它描述等待时间：速率越大，平均等待越短。几何的无记忆是离散次数版，指数是连续时间版，其他寿命分布一般没有此性质。

记 $\phi(z)=e^{-z^2/2}/\sqrt{2\pi}$、$\Phi(z)=P(Z\le z)$（$Z\sim N(0,1)$），分别表示标准正态密度与分布函数。

**正态先标准化整个不等式。** 若 $Z=(X-\mu)/\sigma$，则

$$P(a<X<b)=\Phi\left(\frac{b-\mu}{\sigma}\right)-\Phi\left(\frac{a-\mu}{\sigma}\right),$$

$$\Phi(-z)=1-\Phi(z),\qquad P(|Z|\le z)=2\Phi(z)-1\quad(z\ge0).$$

例：$X\sim N(160,\sigma^2)$、$\sigma>0$，要求 $P(120\le X\le200)\ge0.8$，就写 $2\Phi(40/\sigma)-1\ge0.8$，得 $0<\sigma\le40/\Phi^{-1}(0.9)\approx31.2122$。注意 $N(10,4)$ 的标准差是2。

**标准化与平移伸缩的分布直接写全：** 若 $X\sim N(\mu,\sigma^2)$、$\sigma>0$，则

$$\frac{X-\mu}{\sigma}\sim N(0,1),\qquad aX+b\sim N(a\mu+b,a^2\sigma^2)\quad(a\ne0).$$

$a=0$ 时为常数 $b$。标准差乘的是 $|a|$，不是带正负号的 $a$。

**φ 与一般正态密度的对应：** $\phi$ 专指标准正态密度，而原变量的密度为

$$f_X(x)=\frac1\sigma\phi\left(\frac{x-\mu}{\sigma}\right)=\frac1{\sigma\sqrt{2\pi}}\exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right].$$

不能把外面的 $1/\sigma$ 漏掉；真正求标准化后新变量的密度时，它才与反变换因子 $\sigma$ 抵消。正态平方、两个正态的和差与比值等经典结论，集中列在模块十六；对数正态的密度见模块八，均值方差见模块九。

## 模块七｜CDF：分段、端点与点概率

$$F(x)=P(X\le x),\qquad F(x-)=P(X<x).$$

| 所求事件 | 用 CDF 表示 |
| --- | --- |
| $X=a$ | $F(a)-F(a-)$ |
| $a<X\le b$ | $F(b)-F(a)$ |
| $a<X<b$ | $F(b-)-F(a)$ |
| $a\le X\le b$ | $F(b)-F(a-)$ |
| $a\le X<b$ | $F(b-)-F(a-)$ |
| $X>x$ | $1-F(x)$ |

CDF 不减、右连续，负无穷极限0、正无穷极限1。检查一个候选函数时，这些条件都要满足。证明右连续可取 $x_n\downarrow x$，事件 $\{X\le x_n\}\downarrow\{X\le x\}$，用概率连续性；左极限则对应 $\{X<x\}$，因此跳跃等于点概率。

若有密度，$F(x)=\int_{-\infty}^xf(t)dt$，在可导处 $f(x)=F'(x)$。分段密度积分时，后段必须加上前面已经积累的概率。例如 $f(x)=x$（$0<x<1$）、$2-x$（$1\le x<2$），则

$$F(x)=\begin{cases}0,&x\le0,\\x^2/2,&0<x<1,\\1-(2-x)^2/2,&1\le x<2,\\1,&x\ge2.\end{cases}$$

若 CDF 有跳跃，求导只得到连续部分，不能丢掉点概率。更一般的 CDF 也不能无条件认为“求导就恢复全部分布”；本阶段常见题主要是离散、带密度的连续、以及两者混合。

## 模块八｜变量变换：先找新取值，再选算法

**离散变量：新值相同就合并概率。** $P(g(X)=y)=\sum_{x:g(x)=y}P(X=x)$。例如 $X$ 等可能取 $-1,0,1$，令 $Y=X^2$，则 $P(Y=0)=1/3,P(Y=1)=2/3$。同分布也不等于同一个变量：对称的 $X$ 与 $-X$ 同分布，却通常并不相等。

**CDF 法最通用。** 先写值域，再写 $F_Y(y)=P(g(X)\le y)$，把事件反解回 $X$ 的范围，最后按区域变化分段。只有有密度的部分才能求导。

例：$X\sim U(-1,2),Y=X^2$，当 $y\ge0$，事件是 $-\sqrt y\le X\le\sqrt y$，还要与 $(-1,2)$ 取交集。因此

$$F_Y(y)=\begin{cases}0,&y<0,\\2\sqrt y/3,&0\le y<1,\\(1+\sqrt y)/3,&1\le y<4,\\1,&y\ge4.\end{cases}$$

分子是交集长度，分母是原区间长度3；分段点来自左边先碰到 $-1$、右边后碰到2。相应密度为 $1/(3\sqrt y)$（$0<y<1$）、$1/(6\sqrt y)$（$1<y<4$），其他处0。

**单调可逆时可直接求密度。** 若 $Y=g(X)$ 在原范围内可逆可微，反函数 $x=h(y)$，则

$$f_Y(y)=f_X(h(y))|h'(y)|$$

在新范围内成立，外面为0。先代反解，再乘反函数导数的绝对值。例：$X\sim N(\mu,\sigma^2)$、$Y=e^X$，反解 $x=\ln y$，所以

$$f_Y(y)=\frac1{y\sigma\sqrt{2\pi}}e^{-(\ln y-\mu)^2/(2\sigma^2)},\quad y>0.$$

面积、动能等平方题也这样做：直径 $D>0$、面积 $A=\pi D^2/4$，反解 $d=2\sqrt{a/\pi}$，密度乘 $1/\sqrt{\pi a}$；动能 $T=mV^2/2$、速率 $V>0$，反解 $v=\sqrt{2t/m}$，密度乘 $1/\sqrt{2mt}$。不要把直径当半径。

**非单调时加上所有有效反解。** 在有限个可逆分支上，

$$f_Y(y)=\sum_j f_X(x_j(y))|x_j'(y)|.$$

例如 $Y=X^2$ 的反解为 $\pm\sqrt y$，每支导数绝对值都是 $1/(2\sqrt y)$，但只有落在 $X$ 原范围内的支才计入。又如 $f_X(x)=2x/\pi^2$（$0<x<\pi$），$Y=\sin X$，$0<y<1$ 时两反解是 $a=\arcsin y$ 与 $\pi-a$，故

$$f_Y(y)=\frac{2a/\pi^2+2(\pi-a)/\pi^2}{\sqrt{1-y^2}}=\frac2{\pi\sqrt{1-y^2}}.$$

**一段输入压成一个常数，会产生点概率。** $X\sim U(0,5)$，$X\le1$ 时 $Y=0$，$1<X<3$ 时 $Y=X$，$X\ge3$ 时 $Y=5$。先记 $P(Y=0)=1/5,P(Y=5)=2/5$，再逐段累计：

$$F_Y(y)=\begin{cases}0,&y<0,\\1/5,&0\le y\le1,\\y/5,&1<y<3,\\3/5,&3\le y<5,\\1,&y\ge5.\end{cases}$$

中段 $y/5=1/5+(y-1)/5$，包含已经堆在0处的概率。只交中间的密度 $1/5$ 会漏掉两端共 $3/5$ 的质量。

## 模块九｜期望：把要平均的量直接放进去

$$EX=\sum_x xP(X=x)\quad\text{或}\quad EX=\int xf_X(x)dx.$$

若是给定样本中数值 $x_k$ 出现 $n_k$ 次、总次数 $n=\sum n_k$，样本均值为 $\bar x=\sum_kx_kn_k/n$，即按频数加权。

要有有限期望，要求 $E|X|<\infty$。非负变量允许期望为正无穷；有正有负时不能写成“无穷减无穷”。标准柯西虽对称，但 $\int|x|/[\pi(1+x^2)]dx=\infty$，期望不存在，不能因正负看似抵消就写0。

求函数的期望直接用原分布：

$$E[g(X)]=\sum_xg(x)P(X=x)\quad\text{或}\quad\int g(x)f_X(x)dx,$$

$$E[g(X,Y)]=\iint g(x,y)f_{X,Y}(x,y)dxdy.$$

有正有负时检查绝对可积；非负函数允许结果为无穷。**求期望不用先求新密度，除非新分布反而更方便。**

例：$X\sim U(0,1)$，$E(X^2)=\int_0^1x^2dx=1/3$，但 $(EX)^2=1/4$。不要把期望直接穿过平方、倒数、对数等非线性函数。

线性性 $E(aX+bY+c)=aEX+bEY+c$ 不要求独立；$E(XY)=EX\,EY$ 则需要独立等额外条件，并保证所需期望存在。相同分布且期望存在，就有相同均值，但不用是同一个随机变量。

**分段收益先写函数。** 若需求 $X\sim U(10,20)$、供给 $Y\sim U(10,30)$，两者独立，满足需求的供电每单位利润30、不足部分自供利润10，实际使用单位与原题一致，则利润函数是

$$g(x,y)=30\min(x,y)+10(x-y)_+=\begin{cases}30x,&y\ge x,\\30y+10(x-y),&y<x.\end{cases}$$

求平均利润就把两块分别对联合密度 $1/200$ 积分；同一个函数不能在整个矩形直接套其中一支。常用记号 $(t)_+=\max(t,0)$。

**对数正态矩靠配方。** $X\sim N(\mu,\sigma^2)$ 时，对任意实数 $t$，

$$tx-\frac{(x-\mu)^2}{2\sigma^2}=-\frac{(x-\mu-t\sigma^2)^2}{2\sigma^2}+t\mu+\frac{t^2\sigma^2}{2}.$$

提出常数后，剩下一个正态密度的总积分，所以 $E(e^{tX})=e^{t\mu+t^2\sigma^2/2}$。取 $t=1,2$ 得 $Y=e^X$ 的

$$EY=e^{\mu+\sigma^2/2},\qquad\operatorname{Var}Y=e^{2\mu+\sigma^2}(e^{\sigma^2}-1).$$

## 模块十｜示性变量与对称性：少求一个分布

事件 $A$ 的示性变量 $I_A$ 在发生时为1，否则为0，所以 $EI_A=P(A)$。只要求“发生了多少件事”的平均值时，先把总数拆成0—1记录：

$$N=\sum_{j=1}^mI_{A_j}\quad\Longrightarrow\quad EN=\sum_{j=1}^mP(A_j).$$

事件之间不必独立；这里加的是期望，不是在求并事件概率。

**公交停站例：** 25名乘客独立等概率选7站之一下车，有人下车才停车。令 $I_j$ 表示第 $j$ 站是否停车。该站无人下车概率为 $(6/7)^{25}$，故

$$E(\text{停站数})=7[1-(6/7)^{25}].$$

站与站的停车指标并不独立，但不影响期望相加。一般 $n$ 人独立选 $m$ 个等可能位置，非空位置数期望为 $m[1-(1-1/m)^n]$。

**超几何例：** $N$ 件中 $D$ 件次品，不放回抽 $n$ 件。第 $j$ 个抽样位置拿到次品的无条件概率是 $D/N$，所以次品总数期望为 $nD/N$。已知前面抽取结果后的条件概率会变化，不能说“不放回也独立”。

**份额对称。** $X_1,\ldots,X_n$ 独立同分布且几乎必然为正，令 $S=\sum X_i$。各份额 $X_i/S$ 在 $[0,1]$ 内且分布相同，总和为1，所以

$$E\frac{X_i}S=\frac1n,\qquad E\frac{X_1+\cdots+X_k}S=\frac kn.$$

即使 $EX_i$ 未必有限，份额期望仍存在。这个结论来自对称性，不是把比值期望写成期望的比值。

## 模块十一｜尾和、尾积分与截顶

非负整数值 $N$ 可以看作“跨过了多少个整数门槛”，因此

$$EN=\sum_{k=1}^\infty P(N\ge k)=\sum_{k=0}^\infty P(N>k).$$

因为 $n^2=\sum_{k=1}^n(2k-1)$，同理

$$E(N^2)=\sum_{k=1}^\infty(2k-1)P(N\ge k).$$

尾概率比概率质量容易写时就优先用它们。例如几何 $P(N>k)=q^k$，直接得到 $EN=\sum_{k\ge0}q^k=1/p$。

非负变量不论是否连续，都有

$$\boxed{EX=\int_0^\infty P(X>t)dt.}$$

对单次非负结果 $x$，$x=\int_0^\infty I_{\{x>t\}}dt$；再平均，非负性允许交换平均与积分，即得公式，允许两边同为无穷。若题目给密度，也可从 $\int_0^\infty xf(x)dx$ 中写 $x=\int_0^xdt$，交换区域 $0\le t\le x$ 的积分顺序。

**截顶例：** $X\sim\operatorname{Exp}(\lambda)$，$Y=\min(X,c)$，$c>0$。当 $0\le t<c$，$Y>t$ 等价于 $X>t$；当 $t\ge c$，不可能超过。因此

$$EY=\int_0^c e^{-\lambda t}dt=\frac{1-e^{-\lambda c}}\lambda.$$

按原变量算则是 $\int_0^c xf_X(x)dx+cP(X\ge c)$，末项不能漏：超过上限的结果仍贡献 $c$。对一般非负 $X$，还可用 $E[(X-c)_+]=\int_c^\infty P(X>t)dt$。

可正可负且 $E|X|<\infty$ 时，先拆 $X=X^+-X^-$，得到

$$EX=\int_0^\infty[1-F(t)]dt-\int_{-\infty}^0F(t)dt.$$

负半轴本来可写 $F(t-)$，与 $F(t)$ 的差只在跳点，不影响积分。不能把可能都是无穷的两项直接相减。

## 模块十二｜方差、矩与平方误差

$$\operatorname{Var}X=E[(X-EX)^2]=E(X^2)-(EX)^2,\qquad \operatorname{Var}(aX+b)=a^2\operatorname{Var}X.$$

有二阶矩才使用这些有限量计算；知道方差后求二阶矩则反过来写 $E(X^2)=\operatorname{Var}X+(EX)^2$。平移改变均值但不改变方差。

原点矩 $E(X^k)$ 是直接对幂平均；中心矩 $E[(X-EX)^k]$ 先减均值，二阶中心矩即方差。高阶绝对矩 $E|X|^k$ 可用来检查可积性。

**泊松矩：先消掉阶乘，再移位。** 对 $X\sim\operatorname{Pois}(\lambda)$，

$$kP(X=k)=\lambda P(X=k-1),\qquad k(k-1)P(X=k)=\lambda^2P(X=k-2).$$

分别从 $k=1,2$ 起求和，右边剩下总概率1，得到 $EX=\lambda,E[X(X-1)]=\lambda^2$。用 $X^2=X(X-1)+X$ 补回，得二阶矩 $\lambda^2+\lambda$、方差 $\lambda$。先用 $X(X-1)$ 是因为它恰好约去阶乘的前两个因子。

一般正整数 $m$ 下，$E(X^m)=\lambda E[(X+1)^{m-1}]$；这是把 $k^{m-1}P(X=k-1)$ 的下标改为 $j=k-1$。例如 $EX^3=\lambda(EX^2+2EX+1)=\lambda^3+3\lambda^2+\lambda$。

**标准正态矩：奇数为0，偶数逐级降2。** $Z\sim N(0,1)$，由对称性 $EZ^{2k+1}=0$。利用 $\phi'(z)=-z\phi(z)$ 分部积分，边界项因指数衰减为0，得

$$EZ^{2k}=(2k-1)EZ^{2k-2}=(2k-1)!!,\qquad EZ^0=1.$$

例如 $EZ^4=3$，所以 $\operatorname{Var}(Z^2)=3-1^2=2$。二项可用指标求均值方差，几何可用尾和或等比级数求导；不要只背表而认不出这些入口。

**重尾先判断积分是否收敛。** Pareto 密度为 $k\theta^k x^{-k-1}$（$x>\theta>0,k>0$）时，对正数 $r$，

$$EX^r=k\theta^k\int_\theta^\infty x^{r-k-1}dx=\frac{k\theta^r}{k-r}\quad(r<k),$$

$r\ge k$ 时发散。所以 $k>1$ 才有有限均值 $k\theta/(k-1)$，$k>2$ 才有有限方差 $k\theta^2/[(k-1)^2(k-2)]$。不能把发散积分的形式表达式当成答案。

**用常数预测时，均值使平均平方误差最小。**

$$\boxed{E[(X-c)^2]=\operatorname{Var}X+(EX-c)^2.}$$

把 $X-c=(X-EX)+(EX-c)$ 平方，交叉项含 $E(X-EX)=0$，便得到公式。例：$X$ 各以一半概率取1、3，$EX=2,\operatorname{Var}X=1$，所以任意预测 $c$ 的误差是 $1+(2-c)^2$；$c=2$ 时为1，$c=1$ 时为2。

**只知范围，也能界住方差。** 若 $P(a\le X\le b)=1$，取中点 $c=(a+b)/2$，则 $|X-c|\le(b-a)/2$，故

$$a\le EX\le b,\qquad\operatorname{Var}X\le E[(X-c)^2]\le\frac{(b-a)^2}{4}.$$

这不假设均匀或有密度；端点各占一半时达到上界。

**手算归一化。** 对实际给定的 $d$ 个数 $x_j$，若题目用总体式方差，$m=d^{-1}\sum x_j,v=d^{-1}\sum(x_j-m)^2$，则 $z_j=(x_j-m)/\sqrt v$（$v>0$）均值0、方差1。例如 $(1,3)$ 得 $m=2,v=1,z=(-1,1)$。分母用 $d$ 还是 $d-1$、是否加 $\varepsilon$ 要按题目定义；网络机制本身只需了解。

## 模块十三｜联合分布：先画范围，再积分

离散联合表 $p_{ij}=P(X=x_i,Y=y_j)$ 的每个格子非负、总和为1；求 $X$ 边缘对所有 $j$ 加，求 $Y$ 边缘对所有 $i$ 加。把 $(X,Y)$ 看成同时记录的两个量，$x,y$ 才是一次具体取值；随机向量的函数也可以只有一个数，例如平面距离。

三分类独立重复 $n$ 次，每次概率 $p_1,p_2,p_3$、和为1，前两类次数为 $X,Y$，则

$$P(X=i,Y=j)=\frac{n!}{i!j!(n-i-j)!}p_1^ip_2^jp_3^{n-i-j},\quad i,j\ge0,\ i+j\le n.$$

这来自先安排各类位置、再乘每个序列的概率；两边缘各为二项，但它们通常不独立，因为总次数有限。

连续联合密度满足 $\iint f=1$；区域 $D$ 的概率为 $\iint_D f$。只有“在面积 $A$ 的区域上均匀”时，区域内才有 $f=1/A$。

**一题串起三步：** 密度在 $0<x<y<1$ 上为常数 $c$，区域面积是 $1/2$，故 $c=2$。固定 $x$ 时 $y$ 从 $x$ 到1，固定 $y$ 时 $x$ 从0到 $y$，所以

$$f_X(x)=\int_x^12dy=2(1-x),\quad0<x<1;\qquad f_Y(y)=\int_0^y2dx=2y,\quad0<y<1.$$

其他处为0。若问 $P(Y>2X)$，把新旧范围取交集：$0<x<1/2,2x<y<1$，因此 $\int_0^{1/2}\int_{2x}^12dy\,dx=1/2$。

曲线边界也一样：$0<x<1,x^2<y<x$ 的面积为 $\int_0^1(x-x^2)dx=1/6$，均匀密度是6；求 $Y$ 边缘必须反解成 $y<x<\sqrt y$，不能只交换 $dx,dy$ 而保留旧上下限。

**联合 CDF 累积左下区域。**

$$F(x,y)=P(X\le x,Y\le y)=\int_{-\infty}^x\int_{-\infty}^yf(u,v)dv\,du.$$

矩形概率用四项容斥：

$$P(a<X\le b,c<Y\le d)=F(b,d)-F(a,d)-F(b,c)+F(a,c).$$

联合 CDF 对每坐标不减、右连续，任一坐标趋于负无穷时趋于0，两者趋正无穷时趋于1；只让一个坐标趋于正无穷就得到另一边缘CDF。**还必须满足任意矩形四项差非负**，分别单调并不足够。存在密度且满足相应可微条件时，可由混合二阶导数恢复密度。

## 模块十四｜条件分布与独立性：积分、相除各做什么

离散条件分布就是保留对应一行或一列，再除以这组的总概率：

$$P(X=x_i\mid Y=y_j)=\frac{p_{ij}}{P(Y=y_j)},\qquad P(Y=y_j)>0.$$

连续时改用密度：

$$f_{X\mid Y}(x\mid y)=\frac{f_{X,Y}(x,y)}{f_Y(y)},\qquad f_Y(y)>0.$$

左边读作“给定 $Y=y$ 后，$X$ 在 $x$ 处的密度”，不能用单点概率 $P(Y=y)=0$ 作分母。固定 $y$ 后，它作为 $x$ 的函数必须积分为1。

**三角形例：** 原密度在 $0<x<y<1$ 内为2，$f_Y(y)=2y$。因此给定 $Y=y$ 后 $X\sim U(0,y)$。给定 $y=0.6$，$P(X<0.2\mid Y=0.6)=\int_0^{0.2}(1/0.6)dx=1/3$，分子0.2是符合条件的区间长度。

若给的是 $Y>c$ 而不是 $Y=y$，条件事件有正概率时用区域概率相除：$P(X\in A\mid Y>c)=P(X\in A,Y>c)/P(Y>c)$，不要拿某个切片代替整片区域。

**给定条件密度，反过来组联合。**

$$f(x,y)=f_{X\mid Y}(x\mid y)f_Y(y),\quad f_X(x)=\int f_{X\mid Y}(x\mid t)f_Y(t)dt.$$

再倒推条件，就是连续 Bayes：

$$f_{Y\mid X}(y\mid x)=\frac{f_{X\mid Y}(x\mid y)f_Y(y)}{\int f_{X\mid Y}(x\mid t)f_Y(t)dt},\quad f_X(x)>0.$$

例如 $Y\sim U(0,1)$，给定 $Y=y$ 时 $X\sim U(0,y)$，则联合密度为 $1/y$ 在 $0<x<y<1$；$f_X(x)=\int_x^1dy/y=-\ln x$，所以 $f_{Y\mid X}(y\mid x)=1/[y(-\ln x)]$，$x<y<1$。逐层均匀不表示整个三角形均匀。

**判断独立要覆盖整个范围。** 任意分布用 $F_{X,Y}=F_XF_Y$；离散用每格联合概率等于边缘概率乘积；有联合密度时用 $f_{X,Y}=f_Xf_Y$ 几乎处处。支持范围也必须相容。三角形内常数2即使能写成常数乘积，也不代表独立，因为例如 $X>0.8$ 与 $Y<0.2$ 各有正概率，却不可能在 $X<Y$ 内同时发生。

独立变量分别取函数仍独立。共享一个变量则通常不保证独立：$A=f(X,Y),B=g(X,Z)$、$X,Y,Z$ 独立，给定 $X=x$ 后只剩相互独立的 $Y,Z$，故条件下独立；无条件下可通过 $X$ 产生依赖。反之，给定和 $X+Y=c$ 往往会引入约束，不能由原来独立推出条件下独立。

更一般地，若 $L=l(X,Y)$，$Z$ 与 $(X,Y)$ 独立，$H=h(L,Z)$，则给定 $L$ 后 $H$ 与 $X$ 条件独立；条件只固定 $L$，输出剩下的随机性来自独立的 $Z$。结论要写“不保证独立”，不能把所有情形都说成“必不独立”。

### 给定总数，常见模型会变成什么

- 独立 $X\sim\operatorname{Pois}(\lambda_1),Y\sim\operatorname{Pois}(\lambda_2)$，给定 $X+Y=n$，用联合概率除以和的泊松概率，约去指数与阶乘后，$X\mid X+Y=n\sim B(n,\lambda_1/(\lambda_1+\lambda_2))$。
- 独立 $X,Y\sim B(n,p)$、$0<p<1$，给定总成功数 $m$，$P(X=k\mid X+Y=m)=\binom nk\binom n{m-k}/\binom{2n}m$，$\max(0,m-n)\le k\le\min(n,m)$。两组的 $2n$ 个位置中，总共 $m$ 个成功的位置在条件下等可能。
- 独立同成功率 $0<p<1$ 的重复试验，$T_1,T_2$ 为第一、第二次成功时刻，则 $P(T_1=i,T_2=j)=p^2(1-p)^{j-2}$，$1\le i<j$。给定 $T_2=j$，前一次成功在 $1,\ldots,j-1$ 等可能；给定 $T_1=i$，再等下一次成功所需次数是同参数几何分布。

### 泊松分流：先固定人数，再对人数平均

若 $N\sim\operatorname{Pois}(\lambda)$，每人独立以概率 $p$ 购物，购物数 $Y\mid N=n\sim B(n,p)$。所以

$$\begin{aligned}
P(Y=k)&=\sum_{n=k}^\infty e^{-\lambda}\frac{\lambda^n}{n!}\binom nkp^k(1-p)^{n-k}\\
&=e^{-\lambda}\frac{(\lambda p)^k}{k!}\sum_{r=0}^\infty\frac{[\lambda(1-p)]^r}{r!}
=e^{-\lambda p}\frac{(\lambda p)^k}{k!}.
\end{aligned}$$

因此 $Y\sim\operatorname{Pois}(\lambda p)$。同时记录另一类人数 $Z=N-Y$，其联合概率为

$$P(Y=a,Z=b)=e^{-\lambda}\frac{(\lambda p)^a[\lambda(1-p)]^b}{a!b!},$$

恰好拆成两个泊松概率的乘积，故两类计数独立。**给定总人数时它们互相约束；不固定总人数时却可独立。** 两种问法不能混为一谈。

## 模块十五｜二维函数：和、比值、极值与雅可比

若 $Z=g(X,Y)$，三个入口不同：

$$
\begin{aligned}
P(Z\le c)&=\iint_{g(x,y)\le c}f(x,y)dxdy,\\
F_Z(z)&=\iint_{g(x,y)\le z}f(x,y)dxdy,\\
EZ&=\iint g(x,y)f(x,y)dxdy.
\end{aligned}
$$

所有积分还必须与原支持取交集。第一式算固定事件的一个数；第二式要随阈值 $z$ 分段；第三式在全支持内平均函数值。

### 和的密度：一个取 x，另一个取 z-x

$$f_{X+Y}(z)=\int_{\mathbb R}f_{X,Y}(x,z-x)dx.$$

独立时才写成卷积 $\int f_X(x)f_Y(z-x)dx$。独立整数值变量则是 $P(X+Y=k)=\sum_iP(X=i)P(Y=k-i)$，非独立时保留联合概率。

**例：** $X,Y$ 独立且均为 $U(0,1)$。同时要求 $0<x<1$、$0<z-x<1$，所以 $\max(0,z-1)<x<\min(1,z)$，得到

$$f_{X+Y}(z)=\begin{cases}z,&0<z<1,\\2-z,&1\le z<2,\\0,&\text{其他}.\end{cases}$$

再求 $P(X+Y<1/2)$ 时，积分第一段：$\int_0^{1/2}z\,dz=1/8$。也可直接对正方形内相应三角形积分，结果相同。

独立泊松之和仍泊松，参数相加；独立同成功率的二项之和仍二项，试验次数相加；成功率不同不能直接并成同一个二项。独立指数 $\operatorname{Exp}(\lambda),\operatorname{Exp}(\mu)$ 之和，在 $z>0$ 时

$$f_Z(z)=\begin{cases}\dfrac{\lambda\mu}{\mu-\lambda}(e^{-\lambda z}-e^{-\mu z}),&\lambda\ne\mu,\\\lambda^2ze^{-\lambda z},&\lambda=\mu.\end{cases}$$

这是 $\int_0^z\lambda e^{-\lambda x}\mu e^{-\mu(z-x)}dx$ 的结果。相同速率时不要代入含 $\mu-\lambda$ 的分母；Gamma 名称只需了解。

### 两个输出：先求联合密度，需要时再取边缘

可逆可微变换的反解为 $x=x(u,v),y=y(u,v)$ 时，

$$f_{U,V}(u,v)=f_{X,Y}(x(u,v),y(u,v))\left|\frac{\partial(x,y)}{\partial(u,v)}\right|.$$

按“反解→新区域→反向雅可比→代旧密度后相乘”写，原点等零概率例外可以单独处理。多分支时将有效分支贡献相加。

**例：** 独立 $U(0,1)$ 的 $X,Y$，令 $U=X+Y,V=X-Y$。反解 $x=(u+v)/2,y=(u-v)/2$，雅可比绝对值 $1/2$；原密度为1，因此新密度是 $1\times1/2$，在 $0<u+v<2,0<u-v<2$ 内成立，其他处0。不是在外接矩形里处处为 $1/2$。

雅可比来源于同一区域的概率不变：旧概率 $\iint f(x,y)dxdy$ 换元后面积元乘反向行列式绝对值，故新的被积函数就是新密度。

### 比值：添分母作辅助变量

令 $Z=X/Y,W=Y$，反解 $x=zw,y=w$，雅可比绝对值为 $|w|$，所以

$$f_{Z,W}(z,w)=|w|f_{X,Y}(zw,w),\qquad f_Z(z)=\int_{\mathbb R}|w|f_{X,Y}(zw,w)dw.$$

要求 $P(Y=0)=0$，且积分界由反解同时满足旧范围决定。独立 $U(0,1)$ 的比值有 $0<w<\min(1,1/z)$、$z>0$，故

$$f_Z(z)=\begin{cases}1/2,&0<z\le1,\\1/(2z^2),&z>1,\\0,&z\le0.\end{cases}$$

### 极值：用事件最容易写 CDF，用分支求联合密度

独立同分布 $X,Y$ 的 CDF 为 $F$、密度为 $f$。最大值 $M$ 满足

$$F_M(t)=P(X\le t,Y\le t)=F(t)^2,\qquad f_M(t)=2F(t)f(t).$$

最小值 $L$ 的尾概率为 $P(L>t)=[1-F(t)]^2$。若同时求 $(M,L)$，在 $l<m$ 内有两个原像 $(m,l)$、$(l,m)$，两支雅可比都为1，所以

$$f_{M,L}(m,l)=2f(m)f(l),\quad l<m,$$

还须落在原范围内。例如独立同率指数给 $2\lambda^2e^{-\lambda(m+l)}$，$0<l<m$。若两变量不相同分布，就保留 $f_X(m)f_Y(l)+f_X(l)f_Y(m)$；若不独立，则用原联合密度的两支相加。

### 圆形、平方和与平均距离

遇到 $x^2+y^2$、圆盘或旋转对称密度，优先试 $x=r\cos\theta,y=r\sin\theta$，面积元 $dxdy=r\,dr\,d\theta$。全平面取整周，第一象限只取 $0<\theta<\pi/2$；半径范围也要由旧区域给出。

只求平均距离则可直接积分。$X,Y$ 独立均匀取自 $(0,a)$，

$$E|X-Y|=\frac2{a^2}\int_0^a\int_0^y(y-x)dxdy=\frac2{a^2}\int_0^a\frac{y^2}{2}dy=\frac a3.$$

能乘2，是因为区域、密度、距离都对交换 $x,y$ 对称；一般不对称模型必须分别算两块。

## 模块十六｜二元正态：先查联合正态，再代参数

本模块把经典题的结论集中写全，方便直接查用。以下先设 $(X,Y)$ 为非退化二元正态，均值为 $\mu_1,\mu_2$，标准差 $\sigma_1,\sigma_2>0$，相关系数 $|\rho|<1$。记 $s=(x-\mu_1)/\sigma_1,t=(y-\mu_2)/\sigma_2$，原联合密度为

$$f_{X,Y}(x,y)=\frac1{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}\exp\left[-\frac{s^2-2\rho st+t^2}{2(1-\rho^2)}\right],\quad(x,y)\in\mathbb R^2.$$

两个边缘分别为 $N(\mu_1,\sigma_1^2),N(\mu_2,\sigma_2^2)$，协方差为 $\rho\sigma_1\sigma_2$。**在联合正态前提下，独立等价于 $\rho=0$；仅有两个正态边缘不够。** 同号象限内密度 $2\phi(x)\phi(y)$、其他处0的模型就是反例：边缘均为标准正态，但不是二元正态，相关系数为 $2/\pi$。

### 线性组合与比较大小

**和、差的具体分布：**

$$\boxed{\begin{aligned}
X+Y&\sim N\left(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2+2\rho\sigma_1\sigma_2\right),\\
X-Y&\sim N\left(\mu_1-\mu_2,\ \sigma_1^2+\sigma_2^2-2\rho\sigma_1\sigma_2\right).
\end{aligned}}$$

更一般地，对常数 $a,b,c$，令

$$m=a\mu_1+b\mu_2+c,\qquad v=a^2\sigma_1^2+b^2\sigma_2^2+2ab\rho\sigma_1\sigma_2,$$

则 $aX+bY+c\sim N(m,v)$；$v=0$ 时为常数 $m$。若题目还要密度，且 $v>0$，直接写 $f(z)=e^{-(z-m)^2/(2v)}/\sqrt{2\pi v}$，$z\in\mathbb R$。

**独立同分布的常见特例：** 若 $X,Y$ 独立且均为 $N(\mu,\sigma^2)$，则

$$X+Y\sim N(2\mu,2\sigma^2),\qquad X-Y\sim N(0,2\sigma^2),\qquad\frac{X+Y}{2}\sim N\left(\mu,\frac{\sigma^2}{2}\right).$$

此时和与差还相互独立：它们联合正态，协方差为 $\operatorname{Var}X-\operatorname{Var}Y=0$。若两者方差不同，不能照搬这条独立结论。

**比较谁更大：** 令 $D=X-Y$，记 $m_D=\mu_1-\mu_2$、$s_D^2=\sigma_1^2+\sigma_2^2-2\rho\sigma_1\sigma_2$，则

$$P(X>Y)=P(D>0)=\Phi\left(\frac{m_D}{s_D}\right).$$

例：均值1、2，方差4、9，协方差3，则 $D\sim N(-1,7)$，概率为 $\Phi(-1/\sqrt7)$。

若要求从联合密度证明和的分布，用 $f_{X+Y}(z)=\int f_{X,Y}(x,z-x)dx$，配方后认出正态密度即可；这里不再展开还原过程。

### 给定一个变量后的条件正态

$$\boxed{\begin{aligned}
X\mid Y=y&\sim N\left(\mu_1+\rho\frac{\sigma_1}{\sigma_2}(y-\mu_2),\ \sigma_1^2(1-\rho^2)\right),\\
Y\mid X=x&\sim N\left(\mu_2+\rho\frac{\sigma_2}{\sigma_1}(x-\mu_1),\ \sigma_2^2(1-\rho^2)\right).
\end{aligned}}$$

例如第一式的均值记作 $m_y$、标准差记作 $s_c=\sigma_1\sqrt{1-\rho^2}$，对应密度与概率就是

$$f_{X\mid Y}(x\mid y)=\frac1{s_c}\phi\left(\frac{x-m_y}{s_c}\right),\qquad P(X\le a\mid Y=y)=\Phi\left(\frac{a-m_y}{s_c}\right).$$

条件方差是 $s_c^2$，标准化时除的是 $s_c$。方法只需记住“联合密度除以边缘密度，配方认出正态”；密度前面的 $1/s_c$ 不能漏。

### 两个独立标准正态之比

**本小节额外要求 $X,Y$ 独立且均为 $N(0,1)$。** 令 $Z=X/Y$，保留 $V=Y$ 作辅助变量。方法是反解 $x=zv,y=v$，乘雅可比绝对值 $|v|$，再把 $v$ 积掉。

原联合密度与换元后的联合密度分别为

$$f_{X,Y}(x,y)=\frac1{2\pi}e^{-(x^2+y^2)/2},\qquad (x,y)\in\mathbb R^2,$$

$$\boxed{f_{Z,V}(z,v)=\frac{|v|}{2\pi}\exp\left[-\frac{(1+z^2)v^2}{2}\right],\quad z,v\in\mathbb R.}$$

$v=0$ 是零概率例外，在这条线上可取密度为0。最后的结论是

$$\boxed{f_Z(z)=\frac1{\pi(1+z^2)},\quad z\in\mathbb R.}$$

即标准柯西分布，$F_Z(z)=\frac12+\frac1\pi\arctan z$，通常意义下的期望不存在。这里的标准柯西结论不能直接套给任意相关或非标准的正态比值。

### 标准正态平方、平面距离与平方和

下面仍取 $X,Y$ 独立标准正态；单个平方只用 $X$ 的条件即可。

**单个平方 $T=X^2$：** 两个反解相加，得到

$$F_T(t)=2\Phi(\sqrt t)-1\quad(t\ge0),\qquad f_T(t)=\frac1{\sqrt{2\pi t}}e^{-t/2}\quad(t>0).$$

负半轴 CDF 为0，密度在其余处可取0；$ET=1,\operatorname{Var}T=2$。

**平面距离 $R=\sqrt{X^2+Y^2}$：** 用极坐标，结论为

$$F_R(r)=1-e^{-r^2/2}\quad(r\ge0),\qquad f_R(r)=re^{-r^2/2}\quad(r>0),$$

负半轴 CDF 为0，密度在其余处为0。

**平方和 $S=X^2+Y^2$：** 因为 $S=R^2$，

$$\boxed{S\sim\operatorname{Exp}(1/2),\qquad f_S(s)=\frac12e^{-s/2}\quad(s>0).}$$

这里 $1/2$ 是速率，因此 $ES=2,\operatorname{Var}S=4$；不用先学卡方名称，也能使用以上二维积分结论。

### 半径与角度独立，平方和与比值也独立

独立标准正态变到极坐标后的联合密度是

$$f_{R,\Theta}(r,\theta)=\frac r{2\pi}e^{-r^2/2},\quad r>0,\ 0\le\theta<2\pi,$$

区域外为0。它分成半径密度 $re^{-r^2/2}$ 与角度密度 $1/(2\pi)$，故 $R,\Theta$ 独立。

于是 $S=X^2+Y^2=R^2$ 与 $Z=X/Y=\cot\Theta$ 独立，其联合密度可直接写为

$$\boxed{f_{S,Z}(s,z)=\frac{e^{-s/2}}{2\pi(1+z^2)},\quad s>0,\ z\in\mathbb R,}$$

其他处为0。方法就是先把两个量分别改写成半径、角度的函数，再用独立性。

### 椭圆概率与均匀变量构造正态

**回到一般二元正态参数。** 标准化后令 $U=(X-\mu_1)/\sigma_1,V=(Y-\mu_2)/\sigma_2$。再取

$$Z_1=U,\qquad Z_2=\frac{V-\rho U}{\sqrt{1-\rho^2}},$$

则 $Z_1,Z_2$ 独立标准正态，联合密度为 $\phi(z_1)\phi(z_2)$。这是“配方消交叉项”的换元，不再展开还原联合密度的计算。

对任意实数 $c$，经典椭圆概率为

$$\boxed{P(U^2-2\rho UV+V^2\le c^2)=1-\exp\left[-\frac{c^2}{2(1-\rho^2)}\right].}$$

方法是把椭圆变成圆盘，再用半径CDF；原题二次式没有除以 $1-\rho^2$，答案里的这个尺度不能漏。

**由均匀变量构造正态：** 若 $A,B$ 独立且均为 $U(0,1)$，令

$$U=\sqrt{-2\ln A}\cos(2\pi B),\qquad V=\sqrt{-2\ln A}\sin(2\pi B),$$

则 $U,V$ 独立且均为 $N(0,1)$，联合密度为

$$\boxed{f_{U,V}(u,v)=\frac1{2\pi}e^{-(u^2+v^2)/2}=\phi(u)\phi(v),\quad(u,v)\in\mathbb R^2.}$$

方法只记“先求半径、角度密度，再反向极坐标，密度乘 $1/r$”。换元计算需掌握，生成随机数的应用只需了解。

## 模块十七｜协方差、条件期望与最优预测

二阶矩有限时

$$\operatorname{Cov}(X,Y)=E(XY)-EX\,EY,\qquad\rho_{XY}=\frac{\operatorname{Cov}(X,Y)}{\sqrt{\operatorname{Var}X}\sqrt{\operatorname{Var}Y}},$$

相关系数要求两方差均正，范围 $[-1,1]$；绝对值等于1等价于两变量以概率1满足非零斜率的直线关系。独立推出不相关，反向一般不成立。例如 $X\sim U(-1,1),Y=X^2$，$EX=EX^3=0$，故协方差为0；但 $Y$ 由 $X$ 决定，并不独立。

线性组合的方差是

$$\operatorname{Var}(aX+bY)=a^2\operatorname{Var}X+b^2\operatorname{Var}Y+2ab\operatorname{Cov}(X,Y).$$

例：方差分别4、9，相关系数 $1/3$，先得协方差 $(1/3)\times2\times3=2$，再求 $\operatorname{Var}(X-2Y)=4+36-8=32$。这个计算本身不需要正态。

### 条件期望：组内先平均，再按组的概率平均

离散时 $m(y)=\sum_xxP(X=x\mid Y=y)$；连续时

$$m(y)=E(X\mid Y=y)=\int xf_{X\mid Y}(x\mid y)dx.$$

固定 $y$ 时结果是一个数，写成 $m(y)$ 是函数；代回随机的 $Y$ 得 $E(X\mid Y)=m(Y)$，它是随机变量。若 $E|X|<\infty$，重期望为

$$\boxed{EX=E[E(X\mid Y)]=E[m(Y)].}$$

连续情形用 $f_Y(y)$ 给各组加权，条件密度分母与外层权重抵消；非负 $X$ 也可允许扩展期望。不能把各个条件均值等权平均。

**例：** $f(x,y)=y^{-1}e^{-x/y}e^{-y}$ 在 $x,y>0$，先积分得 $f_Y(y)=e^{-y}$；相除得 $X\mid Y=y$ 为速率 $1/y$ 的指数，所以 $m(y)=y$。于是 $E(X\mid Y=2)=2$，而 $EX=EY=1$，两者所问不同。

随机总数也用这个步骤：$N\sim\operatorname{Pois}(\lambda)$，$X\mid N=n\sim B(n,p)$，则 $EX=E(Np)=\lambda p$。要方差可先算

$$E(X^2\mid N=n)=np(1-p)+n^2p^2,$$

再平均，得到 $EX^2=\lambda p+\lambda^2p^2$，故 $\operatorname{Var}X=\lambda p$。这不必额外调用全方差公式。

### 平方误差预测：给定信息后用条件均值

在某个固定 $Y=y$ 的组内，展开平方同样有

$$E[(X-a)^2\mid Y=y]=\operatorname{Var}(X\mid Y=y)+[m(y)-a]^2.$$

所以最优预测为 $a=m(y)$，最小平均平方误差为条件方差。若按不同 $y$ 使用一个预测函数，逐组最优就是 $m(Y)$。

**例：** $(X_1,X_2)$ 联合标准正态、相关系数0.8，观测 $X_1=1$。条件分布为 $N(0.8,0.36)$，故最优预测0.8、条件标准差0.6。预测0时平方误差为 $0.36+0.8^2=1$；预测0.8时为0.36。预测值不是断言真实值必然等于它。

## 模块十八｜递推期望：加上本轮，再接剩余

选能决定后续的状态，令 $t_s$ 为从该状态起的剩余平均耗时，列

$$t_s=\sum_jP(\text{下一分支 }j\mid s)\,[\text{本轮耗时}+\text{分支后的剩余期望}].$$

终止后剩余为0。若每个分支都先做一局，前面可以统一提出1；耗时不同则分别写，不能都写1。

**返回起点例：** 三门每次独立等概率选择，2小时出洞、3小时回起点、5小时回起点，回来后规则不变。则

$$t=\frac13\,2+\frac13(3+t)+\frac13(5+t),\qquad t=10.$$

每次成功率 $1/3$、每次耗时至多5小时，故期望有限，可以解这个方程。规则若会记住走过哪些门，就不能把所有返回都记作同一个 $t$。

**连胜两局例：** 甲、乙每局独立胜率 $p,q=1-p$，$0<p<1$，任一人连胜两局就停。设刚由甲赢一局时还需平均 $a$ 局，刚由乙赢时为 $b$，初始为 $t$：

$$a=p(1+0)+q(1+b)=1+qb,\quad b=q(1+0)+p(1+a)=1+pa,$$

$$t=1+pa+qb.$$

解得 $a=(1+q)/(1-pq),b=(1+p)/(1-pq)$，所以

$$t=\frac{2+pq}{1-pq}\le3,$$

因为 $pq\le1/4$，等号在 $p=q=1/2$。这里 $a,b$ 不包含已经结束的上一局，式中的1是即将进行的一局。每个两局块至少有 $p^2+q^2>0$ 的概率因两局同胜者而结束，足以保证等待期望有限。

## 模块十九｜证明题常用的几种起笔

**要证非负变量几乎必然为零，就抓住一个正门槛。** 若 $X\ge0,EX=0$，对任意整数 $n\ge1$ 有 $X\ge n^{-1}I_{\{X\ge1/n\}}$，取期望得 $P(X\ge1/n)=0$。又 $\{X>0\}=\bigcup_{n\ge1}\{X\ge1/n\}$，故 $P(X>0)=0$。不能仅从“非负函数积分为零”就断言每个点都为零。

零方差同理：$E[(X-EX)^2]=0$ 推出 $X=EX$ 以概率1成立。这里“几乎必然”允许零概率例外，不是逐个样本结果都必须相同。

**要证相关系数的界，造一个平方。** 令 $A=X-EX,B=Y-EY$，在 $EA^2>0$ 时取 $c=E(AB)/EA^2$，则

$$0\le E(B-cA)^2=EB^2-\frac{[E(AB)]^2}{EA^2}.$$

移项得 $\operatorname{Cov}(X,Y)^2\le\operatorname{Var}X\operatorname{Var}Y$。两方差正时除以它们的乘积，得 $|\rho|\le1$；等号时平方期望为零，故 $B=cA$ 几乎必然。若某方差为零，协方差为零但相关系数无定义。

同样，$\operatorname{Var}(|X|)\ge0$ 给 $(E|X|)^2\le EX^2$，所以二阶矩有限会保证一阶绝对矩有限。算出有限均值并不保证有限方差。

**求和证明遇到“$k$ 乘组合数/阶乘”，先约掉它。** 泊松用 $k/k!=1/(k-1)!$；超几何均值还可用

$$k\binom Dk=D\binom{D-1}{k-1},\qquad\sum_k\binom{D-1}{k-1}\binom{N-D}{n-k}=\binom{N-1}{n-1}.$$

代入期望和，得到 $EX=D\binom{N-1}{n-1}/\binom Nn=nD/N$。第二个等式是 Vandermonde 的计数求和。每次移位都要一起改幂、阶乘、概率下标和求和起点。

**正态归一化用“平方后变二维”。** 记 $I=\int_{\mathbb R}e^{-x^2/2}dx>0$，非负积分允许相乘并换序：

$$I^2=\iint e^{-(x^2+y^2)/2}dxdy=\int_0^{2\pi}\int_0^\infty e^{-r^2/2}r\,dr\,d\theta=2\pi.$$

因此 $I=\sqrt{2\pi}$，标准正态密度总积分为1。极坐标中的半径因子不能漏。

**证明分布公式，回到它能算概率这件事。** CDF 证明先把不等式翻成事件；密度换元证明对任意新区域算概率，再换回原区域积分；重期望证明将条件概率或条件密度展开，外层权重抵消分母。需要交换有符号和/积分时，检查绝对可积；非负函数可允许无穷。不必为一个计算题搬出与它无关的抽象定义。

### 概率公理、连续性与严格定义

概率空间 $(\Omega,\mathcal F,P)$ 分别表示所有可能结果、可谈概率的事件集合、给事件赋概率的规则。$P\ge0,P(\Omega)=1$，可数个互斥事件的并概率等于各项之和。

递增事件 $A_n\uparrow A$ 或递减事件 $A_n\downarrow A$，有 $P(A_n)\to P(A)$；并集上界 $P(\bigcup_i A_i)\le\sum_iP(A_i)$ 不要求独立。严格的随机变量定义要求 $\{X\le x\}$ 是可测事件；可测函数复合仍是随机变量。一般期望可通过离散近似建立，这些构造不需替代已经会用的求和、积分公式。

### 三个不等式与散度

| 条件与结论 | 用途与不能混淆的地方 |
| --- | --- |
| $X\ge0,EX<\infty,a>0$：$P(X\ge a)\le EX/a$ | Markov，用平均大小控制大值概率；结果只是上界 |
| $g\ge0$ 且单调不减，$g(a)>0$：$P(X\ge a)\le Eg(X)/g(a)$ | 非负 $X$ 的广义形式，要求相应期望有限 |
| 方差有限、$a>0$：$P(|X-EX|\ge a)\le\operatorname{Var}X/a^2$ | Chebyshev，不要求正态 |
| $g$ 凸、所需期望存在：$g(EX)\le E[g(X)]$ | Jensen，不能把任意非线性函数穿过期望 |

对正态变量，均值两侧 $2\sigma$ 外的精确概率为 $2[1-\Phi(2)]$，不是把切比雪夫上界 $1/4$ 当作精确值。凸函数 $|x|^\alpha$ 给 $E|X|\le(E|X|^\alpha)^{1/\alpha}$（$\alpha\ge1$、高阶矩有限）。

离散概率向量的 KL 为 $\sum_i p_i\log(p_i/q_i)\ge0$：可用 $-\log$ 的凸性理解；若 $p_i>0,q_i=0$ 则为无穷，不能硬算有限对数。一般凸函数散度可写成 $\sum_i q_i f(p_i/q_i)$，在 $q_i>0,f(1)=0$ 时由加权平均与凸性得到非负。这里只需认识用途，不扩展成新的证明训练。

### Gamma 与相关积分

$$\Gamma(\alpha)=\int_0^\infty t^{\alpha-1}e^{-t}dt,\quad\alpha>0;\qquad\Gamma(\alpha+1)=\alpha\Gamma(\alpha),$$

$$\Gamma(1)=1,\quad\Gamma(1/2)=\sqrt\pi,\quad\Gamma(n)=(n-1)!.$$

形状 $\alpha$、速率 $\beta>0$ 的 Gamma 密度为 $\beta^\alpha x^{\alpha-1}e^{-\beta x}/\Gamma(\alpha)$（$x>0$），均值 $\alpha/\beta$、方差 $\alpha/\beta^2$。参数若采用尺度而非速率，公式不能照抄。遇到幂乘指数可用

$$\int_0^\infty x^{\alpha-1}e^{-\beta x}dx=\frac{\Gamma(\alpha)}{\beta^\alpha}.$$

指数是形状1的特例。指数尾函数满足 $S'(t)=-\lambda S(t)$，这是无记忆模型的微分方程联系，只需了解。

### 分位数、广义反函数与抽样

课程一般分位数定义为 $P(X<a)\le p\le P(X\le a)$，$p=1/2$ 时为中位数，离散情形可能不唯一。均值看加权数值，中位数看累计位置，两者不是一个概念。

广义反函数 $Q(p)=\inf\{x:F(x)\ge p\}$ 取最左侧达到累计概率 $p$ 的位置。例：$P(X=0)=P(X=2)=1/2$，课程中位数可为 $[0,2]$ 内任意数，而 $Q(1/2)=0$。库存题若要求 $P(X\le q)>0.99$，要找使累计概率严格超过0.99的最小整数，还要检查前一个整数不满足；不能忘掉严格不等号。

若 $U\sim U(0,1)$，则 $Q(U)$ 服从 CDF 为 $F$ 的分布；若 $F$ 连续且 $X$ 的 CDF 为 $F$，则 $F(X)\sim U(0,1)$。有跳跃的离散CDF不能直接套后一结论。

### 全方差与 AI 应用背景

二阶矩有限时，$\operatorname{Var}X=E[\operatorname{Var}(X\mid Y)]+\operatorname{Var}(E[X\mid Y])$，表示组内波动与组均值波动合成总波动。它是本课程的补充联系；前面的随机总数题已经示范了不用它也能算方差的方法。

初始化、BatchNorm/LayerNorm/RMSNorm、残差与生成器的机制只需了解。计算均值方差时仍按指定维度与公式；一般非线性生成器不保留正态形状，不能因为输入正态就断言输出正态。用密度分类时比较“先验 × 类别条件密度”，先验相同时才只比较密度；没有具体参数就不能编造数值后验。概率思想的发展史不增加新的计算公式。

## 最后查漏｜常用计算工具与答题检查

| 运算 | 复习时要能直接使用 |
| --- | --- |
| 有限等比和 | $\sum_{k=0}^nq^k=(1-q^{n+1})/(1-q)$，$q\ne1$ |
| 无穷等比和 | $\sum_{k=0}^\infty q^k=1/(1-q)$，$|q|<1$ |
| 级数求导 | $\sum_{k=1}^\infty kq^{k-1}=1/(1-q)^2$，$|q|<1$ |
| 常用整数和 | $\sum_{k=1}^n k=n(n+1)/2$；$\sum_{k=1}^n k^2=n(n+1)(2n+1)/6$ |
| 指数级数 | $\sum_{k=0}^\infty a^k/k!=e^a$ |
| 幂函数积分 | $\int x^r dx=x^{r+1}/(r+1)$，$r\ne-1$；$\int dx/x=\ln|x|$ |
| 指数积分 | $\int e^{-ax}dx=-e^{-ax}/a$，$a\ne0$ |
| 分部积分 | $\int u\,dv=uv-\int v\,du$，常用于幂乘指数、正态矩 |
| 常见导数 | $(\ln x)'=1/x$；$(\arctan x)'=1/(1+x^2)$；$(\arcsin x)'=1/\sqrt{1-x^2}$ |
| 二阶行列式 | $\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc$；密度换元取绝对值 |

例如极坐标后的 $I_m=\int_0^\infty r^m e^{-r^2}dr$，$m>1$ 时分部积分给 $I_m=(m-1)I_{m-2}/2$，配合 $I_0=\sqrt\pi/2,I_1=1/2$ 即可算整数次幂，不必先使用 Gamma 名称。

做完一道题，用下面几项快速核对，而不是把原解答重算一遍：

- 概率是否在 $[0,1]$，分布列或密度是否归一化，CDF 是否不减且端点为0、1？
- 支持范围有没有写全，条件是否改了样本空间，常数压缩是否漏掉点概率？
- 乘概率有没有独立性依据，条件分布是不是除了正确的边缘？
- 求密度乘的是反变换导数/雅可比，最终求一个变量时有没有积掉辅助变量？
- 方差是否非负，标准化除的是标准差，线性组合有没有协方差交叉项？
- 近似是否标明条件，等号是否只在特殊情形成立，均值和方差是否确实存在？
